RefraInspector v13.0 Beta — Help & User Manual

RN Plate Pair Inspector · Upper / Lower inspection workflow

Quick start — Import the Upper and Lower plate photographs, level each image if necessary, run ruler calibration independently for each PL, adjust A–F measurement lines, and export the pair report. Manual inputs remain available when image detection is uncertain.
1. Photos2. Leveling3. Calibration4. A–F5. Areas6. Pair results7. Export8. Troubleshooting9. Contact

1. Import photographs

  1. Select Upper PL or Lower PL. In the empty photo area, choose Import PL photo.
  2. Import a single image for the currently selected PL, or select two images together (the first file is assigned Upper, the second Lower).
  3. Wait for the loading indicator to disappear. Once loaded, use the exchange/replace icon at the photo workspace's top-right to replace an image.
  4. Switch between Upper and Lower tabs to confirm each image is assigned correctly.

On iPhone, photo import keeps the image at a mobile-safe working resolution; use the original source for any higher-precision forensic review. JPEG/JPG, PNG, WebP and HEIC/HEIF are supported by the import workflow. On browsers without native HEIC support, conversion libraries may need an internet connection; some HEIC encodings remain unsupported.

2. Image orientation

Use Auto level for automatic correction or Level by 2 points to indicate a horizontal reference on the photo. Select two points on the same straight reference (preferably the horizontal ruler edge). The photo is rotated to level that reference.

Leveling changes the displayed image geometry. If auto ruler calibration becomes unreliable after leveling, try detecting ticks before leveling or use manual 100 mm calibration. Do not assume the two PL photos have identical pixel scales.

3. Ruler calibration (px/mm)

  1. For each Upper/Lower photo, open Ruler calibration · X / Y (px/mm) and click Auto 100mm Calibration.
  2. Inspect both Horizontal ruler (px/mm) and Vertical ruler (px/mm), together with detection warnings. Two axes should generally be similar in an almost perpendicular photograph, but not necessarily identical.
  3. If automatic detection fails or is questionable, click Start Manual Calibration, align the two vertical guides with a 100 mm interval along the horizontal ruler, and align the two horizontal guides with a 100 mm interval along the vertical ruler. Click Finish Manual Calibration to restore the normal dimension lines.
  4. You can also enter independently verified px/mm values directly in the X/Y fields.

Scale = pixel distance ÷ 100 mm. Upper and Lower are calibrated independently. A successful automated estimate must still be checked against visible ruler marks for quantitative work.

4. A–F dimensions

Auto Align Features · v9.3 Beta: fits inner used-bore and outer damage ellipses, rejects outlier dots, and aligns their guide lines. Contour dots and fitted ellipse outlines remain hidden at all times. H1/H6 are detected separately; physical damage boundaries still require inspector confirmation. Use Undo Alignment to restore the prior guides. Confidence describes image geometry, not proven physical accuracy.

Drag the six horizontal (H1–H6) and two vertical (V1–V2) measurement guides over the current plate photo. Use the PL A–F Dimensions · Upper / Lower panel to view values side by side.

  • Auto reads the corresponding line-to-line distance using the photo's px/mm calibration.
  • Manual lets you enter the dimension measured with physical tools. The manual entry field appears only when Manual is selected.
  • Selected values are emphasized and unused values are grey. Lines H4/H5/H6 may overlap; their individual handles remain movable.
  • Use Reset lines to restore the default positions for the selected image.

Dimension definitions and placements are shown by the small i help icon in the photo workspace. Photo-derived A–F measurements are estimates until line placement and calibration are validated.

5. Bore enlargement and edge damage

Under Nested ellipse area model, the used-bore inner ellipse is determined from H3/H4 and estimated left/right bore edges; the outer edge-damage ellipse is bounded by V1/V2/H2/H5. Click Detect bore left/right from photo to update the inner horizontal boundaries.

OutputMeaning
Used bore area (mm²)Full inner ellipse area, scaled from image to mm².
ΔBore area (mm²)Used bore area − π × Y₀², where Y₀ is the unused bore radius.
ΔBore area (%)100 × ΔBore area / (π × Y₀²).
Edge damage (mm²)Estimated outer elliptical area excluding the used-bore inner area.
These are ellipse-based approximations, not validated automatic corrosion/damage segmentation. The original bore radius Y₀ and reliable X/Y scales are needed for meaningful numerical results.

6. Campaign and PL pair information

Use PL Geometry for campaign ID, W, X, Y₀, Z, R₀ and the remaining-stroke safety limit. The bulk-paste box accepts PL geometry from Excel/TSV; H₀ = 2Y₀ is calculated. In PL Set Usage Info, enter Pair ID, total runtime and heats used (shared by Upper and Lower).

Long-end damage: T = F − (W − X + Y₀) for each PL. Remaining stroke: R = Z − Tupper − Tlower − 2Y₀. Stroke reduction: ΔR = R₀ − R. Rate results depend on the runtime and heat-count inputs. Use PL Performance to review saved campaign-level pair statistics.

Cracks candidate detection is experimental: review and correct counts manually. Remarks tags and free text are stored independently for Upper and Lower.

Mobile layout and touch adjustment (v13.0)

On iPhone and narrow screens, scroll vertically through PL Geometry, PL Photo Workspace and Results in one continuous page. The mobile header uses a compact ? manual button; desktop-only copy and backup controls are hidden on small screens, but local recovery remains active. For precise H1–H6 / V1–V2 placement, dimensional lines appear thinner on mobile while their invisible drag targets are enlarged. Enlarged touch regions do not affect image coordinates, pixel-to-mm calibration, recorded A–F measurements or alignment verification. Use inspection verification before committing measurements to the Campaign.

7. Saving and exporting

  • Save set to campaign stores the current pair in this browser session for performance summaries. Export your data before closing the page.
  • Copy PLs data copies Mark (or Abbreviation if Mark is blank) plus Upper and Lower PL values; numeric data uses one decimal place. Missing or unsupported values are blank; shared pair results appear in the Upper column.
  • Export pair JSON + images downloads the pair data and annotated photos.

8. Troubleshooting and measurement limits

SymptomWhat to do
Ruler detection failsEnsure both rulers and several 10 mm ticks are visible; avoid severe tilt, glare and blur. Retry, then use manual 100 mm spans if necessary.
Vertical px/mm seems too lowCheck the exact 100 mm span on the vertical ruler and calibrate Y manually; do not copy the horizontal value as proof.
Upper and Lower show the same px/mmRe-run detection separately on each photo and compare against a known 100 mm ruler span. Similar numbers can occur, but identical values alone do not establish correctness.
Photo imports but warning appearsCheck whether the image actually loaded. A post-import analysis warning may not be a photo decode failure.
A–F or area results greyed outComplete and verify the required horizontal/vertical px/mm calibration, or select Manual for dimension entry.

Accuracy goal (future): ±2 mm versus manual A–F measurements, with onsite photography and increasingly automated post-processing. This is a development target, not a certified current accuracy specification.
